# Support

Start with the [documentation site](https://nix-forge.github.io/nix-seal/) and
the repository README. They describe the supported NixOS, nix-darwin, and Home
Manager integrations, release status, and known limits.

For a bug or a reproducible configuration problem, [open an issue](https://github.com/nix-forge/nix-seal/issues/new).
Include the version or commit, operating system, relevant configuration, the
command that failed, and the smallest useful log excerpt. Remove secrets and
private identities before posting.

Use [SECURITY.md](SECURITY.md) for suspected vulnerabilities. Do not disclose
security-sensitive details in a public issue.

This project does not provide managed deployments or private system
administration. Questions about a local deployment are welcome when they are
reduced to a public, reproducible example.
