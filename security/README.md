# Security evidence

This directory contains public, machine-readable security evidence. It never
contains credentials, plaintext secrets, or private incident details.

vex.json is an OpenVEX document. An empty statements array means that this
repository has no current non-affectability assertion to publish. Add a
statement only after reviewing a dependency vulnerability against a released
component. User-impacting issues belong in [SECURITY.md](../SECURITY.md) and
GitHub private vulnerability reporting.
